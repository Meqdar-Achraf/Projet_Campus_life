# IAASWW

Bienvenue sur le projet `Campus life`.

Ce dépot contient une représentation visuelle et une structure de site web concue avec des technologies front-end basées  sur du HTML et du CSS.

## Description du projet

`campus life` est un projet web qui met en avant :

- une mise en page moderne ;
- des styles personnalisés avec CSS ;
- une structure HTML simple et lisible ;

## Composition technique

Le dépot est principalement composé de :

- HTML : pour la structure du contenu ;
- CSS : pour la mise en forme, les couleurs, les espacements et le design global.

## Objectif général

L'objectif principal de projet est de fournir :

- une interface visuelle attractive ;
- une navigation simple ;

## Structure probable du projet

le projet généralement contenir :

- des fichier HTML (page: acceuill, campus et inscription)  ;
- des feuilles de style CSS ;
- des ressources graphiques ;
